# Приглашение на юбилей

Готовый статический сайт. Персонаж и все изображения встроены в index.html. Установка и сборка не нужны. Шрифты загружаются из Google Fonts; без интернета используются запасные шрифты.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного GitHub Pages выберите Public. Сайт и его исходники будут общедоступны.
2. Распакуйте архив. Через Add file → Upload files загрузите файлы index.html, README.md и .nojekyll в корень репозитория. Сам ZIP загружать не нужно.
3. Нажмите Commit changes.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, затем main и / (root). Нажмите Save.
6. После завершения публикации ссылка появится в разделе Pages.

Чтобы изменить сайт, замените index.html новой версией и сохраните изменения.
